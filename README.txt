SSC CGL Vocabulary Lab — PWA

Files:
- index.html       Main responsive web app
- manifest.webmanifest  Installable PWA manifest
- sw.js            Offline service worker
- icons/           PWA icons

Run on web:
1. Serve this folder over HTTP/HTTPS (for example with VS Code Live Server or: python -m http.server 8000)
2. Open http://localhost:8000/
3. Use the browser Install option to install it as a desktop/mobile app.

Important: Service workers and PWA installation do not work from file:// directly.
